## Remaining work and release gates

1. **MikroTik live integration:** validate a real RouterOS connection against a lab router and test PPPoE add/disable/enable/profile changes using a disposable account. Current PPPoE records or inventory are not proof that a router was changed.
2. **HSGQ-G04R / ONU:** obtain supported vendor API/CLI documentation and validate read-only OLT/ONU telemetry before enabling control operations.
3. **TR-069 / GenieACS:** configure a real ACS endpoint and test inform, parameter reads and safe provisioning on a test ONU. No live ACS/ONU session was verified in this audit.
4. **Messaging:** configure Meta-approved WhatsApp templates and secrets, then verify webhook signatures, queue delivery and provider receipts using a controlled test number.
5. **Real tenant workflows:** provision a test tenant and customers in staging; verify subscription lifecycle, invoice generation, partial/full payments, refunds, ticket permissions, portal provisioning and cross-tenant denial.
6. **Backup recovery:** retain the documented production D1 export outside Git and perform a restore drill into an isolated test database. A recorded export is not the same as a successful restore drill.
7. **Production readiness:** complete an independent security review, operational monitoring/alerting review, data-retention policy and customer-data backup/restore exercise before relying on NEXUS as the sole production system of record.
